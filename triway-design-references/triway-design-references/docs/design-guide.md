# TRIWAY design guide
Light mode only. Inter 400/600/800. Source of truth: foundations/design-tokens.json and shared/tokens.css.
## Approved
Emerald #064E3B, Green #147D64, Mint #CFE5CF, Background #F0F7F3, Surface #FFF, Text #111, Muted #6B7280, Danger #C0392B, gradient #1F6B4F to #3F9680 (brand elements only).
## Proposed (need approval)
Warning #B45309, border #D5E3DA, disabled #9CA3AF, overlay rgba(17,17,17,.5). Type scale from the brief is treated as proposed.
## Rules
- 4px spacing; 20px screen margin; radii 12/16/20; pill primary buttons; 48dp minimum touch targets.
- Cards use a soft shadow; route "tickets" with a dotted fare stub are the signature element.
- Line icons: 24px, 2px stroke, round caps, currentColor.
- Statuses always pair an icon or text with color.
- Motion: see foundations/motion.md.
